# simple-ideas Homebrew tap

[si](https://github.com/felipeg48/simple-ideas) turns Markdown into animated,
fluid HTML slide decks, articles, guides, books and mind maps.

```sh
brew install felipeg48/tap/si                 # the si command (macOS, Linux)
brew install --cask felipeg48/tap/si-studio   # si Studio, the Mac app
```

`brew upgrade` keeps them current. The formula and the cask are written by
simple-ideas' release workflow on every release (`packaging/homebrew.sh`);
do not edit them here.
